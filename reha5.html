第1部 しくみ

1しくみ：守る・動かす・神経の高さ

どの病気にも共通する2つの考え方

運動器のリハは、①守ることと動かすことを時期に合わせて両立させる、②症状を神経の高さ（神経根・髄節）と結びつける、の2つで多くが説明できる。

守ると動かすの両立

場面守る動かす
腱板縫合術後装具3〜8週、肘の運動も避ける装具中は手・指のROM
橈骨遠位端骨折ギプス4〜6週挙上して手指の屈伸（浮腫予防）
大腿骨近位部骨折荷重制限・脱臼肢位手術翌日から座位、足関節の運動（DVT予防）
アキレス腱縫合術後6〜8週は腱を伸ばさない患部以外の筋力訓練

神経の高さと結びつける

つながり

腰の病気（SLR・FNST） 脊髄損傷（key muscle・横隔膜・自律神経過反射） 大腿骨近位部骨折（早期離床・DVT）

見ないで言ってみよう

SLRテストとFNSTは、それぞれどの神経根の障害を見る？

SLR＝L5・S1、FNST＝L2〜L4。

C6・L3・L4のkey muscleの運動は？

C6＝手関節背屈、L3＝膝伸展、L4＝足背屈。

ノートにまとめる

要点
  • 守る（固定・装具・荷重制限）と動かす（拘縮・廃用・浮腫・DVT予防）の両立
  • SLR＝L5・S1、FNST＝L2〜L4、横隔膜＝C3〜C5
  • key muscle：C5肘屈曲・C6手関節背屈・C7肘伸展・C8中指屈曲・T1小指外転／L2股屈曲・L3膝伸展・L4足背屈・L5母趾伸展・S1足底屈

確認問題

key muscleでC6に対応する運動はどれか。

  1. 肘屈曲
  2. 手関節背屈
  3. 肘伸展
  4. 小指外転
C5肘屈曲、C6手関節背屈、C7肘伸展、C8中指屈曲、T1小指外転。

大腿神経伸展テスト（FNST）で痛みが出たら、神経根の障害を考える。

SLRテストはL5・S1。

第2部 上肢

2肩：腱板損傷・肩関節周囲炎

腱が切れたのか、肩が固まったのか

腱板損傷は肩を支える4つの腱（ローテーターカフ）が切れ、痛み・夜間痛・挙上の脱力が出る。肩関節周囲炎（五十肩・凍結肩）は炎症から拘縮へ進み、1〜2年かけて回復する。

腱板損傷

50歳以上の男性・右肩。棘上筋が最多。無症候性も半数以上。保存療法が第一選択

肩関節周囲炎

50歳代中心、頻度約5%。糖尿病で数倍多く難治化。X線は異常なし

どの腱？ 筋ごとのテスト

ペインフルアーク

自動外転60〜120°だけ痛い → 棘上筋

ドロップアーム

90°外転を保持できず落ちる → 広範囲断裂

自動と他動

自動ROM＜他動ROMなら腱板（筋）の問題、他動から制限されていれば拘縮

腱板損傷のリハ

項目ポイント
基本方針損傷を広げない＋残った部分の廃用を防ぐ。外転・外旋・痛む動作に注意
ROM訓練痛みと相談しながらゆっくり。コッドマン体操（前傾して腕を振る）は棘上筋に負担なし
筋力訓練チューブで筋ごとに低負荷から。僧帽筋・前鋸筋・菱形筋も
術後装具3〜8週。装具中は手・指のROMのみ（肘も避ける）。術後3か月は5kg以上を持たない
ADL指導肘を体幹につけ、手を体の前・近くで使う

肩関節周囲炎の3つの時期

急性期

除痛とROM維持（三角巾・温熱・おじぎ運動）

慢性期

拘縮の解除（コッドマン体操など）

回復期

肩周囲筋の強化

どの時期も無理な他動運動は禁忌。急性期の侵襲の大きい手術は複合性局所疼痛症候群を誘発しうる。

生活指導：着衣は患側の袖から。就寝時は肩〜肘の後ろにタオルやクッションを入れ、軽度内旋位に。

つながり

腱板が骨頭を引き寄せて外転の軸をつくるしくみ（運動学）、コッドマン体操（治療学）とつなげよう。

テーマ3 上腕骨近位部骨折（腱板損傷の合併）

施術の場面で気づきたいこと

  • 肩の痛みは虚血性心疾患の関連痛のことがある。整形外科の病気と思い込まず、胸部症状や労作との関係を問診する。
  • 肩関節周囲炎の人の肩を無理に他動的に動かさない。痛みの強い急性期は特に注意。

見ないで言ってみよう

棘上筋・棘下筋（小円筋）・肩甲下筋を見るテストは？

棘上筋＝full can／empty can、棘下筋・小円筋＝外旋ラグ検査、肩甲下筋＝リフトオフテスト。

肩関節周囲炎の3つの病期と期間は？

急性期（freezing）→ 慢性期（frozen）→ 回復期（thawing）。各4〜6か月、全体で1〜2年。

ノートにまとめる

要点
  • 腱板損傷：棘上筋が最多、保存が第一、術後3か月は5kg以上持たない
  • ペインフルアーク60〜120°・ドロップアーム
  • 肩関節周囲炎：糖尿病で難治、freezing → frozen → thawing（1〜2年）
  • 無理な他動運動は禁忌、着衣は患側から
  • 肩の痛みは心疾患の関連痛のことも

確認問題

肩甲下筋の筋力を評価するテストはどれか。

  1. full canテスト
  2. 外旋ラグ検査
  3. リフトオフテスト
  4. ドロップアームテスト
手背を背中に当てた位置から手を後ろへ離せなければ陽性。

肩関節周囲炎について正しいのはどれか。

  1. 糖尿病があると難治化しやすい
  2. X線で特徴的な所見がある
  3. 慢性期は痛みが最も強い
  4. 他動運動で積極的に動かす
X線は異常なし、痛みが最強なのは急性期、無理な他動運動は禁忌。

肩関節周囲炎の患者が服を着るときはの袖から通す。

患側の動きを最小限にする。

第2部 上肢

3上肢の骨折

転んで手をつく → 骨粗鬆症の骨が折れる

上腕骨近位部骨折と橈骨遠位端骨折は、骨粗鬆症のある中高年の女性が転倒して起こりやすい。固定中も固定していない関節を動かすことが大切。

骨折の型と治療

上腕骨近位部骨折橈骨遠位端骨折
分類Neer分類（転位した骨片の数で1〜4-part）。1-partは保存、2-part以上は手術を考慮コレス骨折（背側転位・フォーク状変形・最多）、スミス骨折（掌側転位）、バートン骨折（関節内）
治療三角巾・バストバンドで固定し1〜4週後から動かす。手術：プレート・髄内釘・人工骨頭（4-part）保存70%前後：整復＋ギプス4〜6週。手術：プレート固定（固定約3週）
合併症腋窩神経損傷、20〜50%に腱板損傷長母指伸筋腱断裂・手根管症候群・複合性局所疼痛症候群

固定中のリハ

上腕骨近位部骨折

固定中は肘・手・指のROM。三角巾は上方へ確実に牽引（不足すると肩甲骨の下方回旋で痛む）、腋にタオルを挟み約30°外転

橈骨遠位端骨折

ギプス中は患肢を心臓より高く挙上し、手指の屈伸で浮腫を防ぐ。握力の回復はROMより遅い

つながり

テーマ1 守ると動かす テーマ2 腱板損傷 テーマ10 骨粗鬆症と椎体骨折

施術の場面で意識したいこと

  • ギプスや三角巾で固定中の人には、固定部を動かさず、指示された範囲で手指などを動かせているか確かめる。
  • 手指の強い腫れ・しびれ・色の変化が出たら、固定の担当医療機関への連絡をすすめる。

見ないで言ってみよう

コレス骨折とスミス骨折の違いは？

コレス＝遠位骨片が背側に転位（フォーク状変形・最多）、スミス＝掌側に転位。

上腕骨近位部骨折で三角巾を着けるポイントを2つ。

上方へ確実に牽引する、腋にタオルを挟み約30°外転。

ノートにまとめる

要点
  • 上腕骨近位部：骨粗鬆症の高齢女性、Neer分類、腋窩神経損傷・腱板損傷の合併
  • 橈骨遠位端：手をつく、コレス骨折、長母指伸筋腱断裂
  • 固定中も肘・手・指を動かす、挙上して手指屈伸
  • 握力の回復はROMより遅い

確認問題

橈骨遠位端骨折で遠位骨片が背側に転位し、フォーク状変形を示すものはどれか。

  1. スミス骨折
  2. コレス骨折
  3. バートン骨折
  4. モンテジア骨折
コレス骨折。最も多い型。

橈骨遠位端骨折の合併症として教科書に挙げられているのはどれか。

  1. 腋窩神経損傷
  2. 腱板損傷
  3. 大腿骨頭壊死
  4. 長母指伸筋腱断裂
長母指伸筋腱断裂・手根管症候群・複合性局所疼痛症候群。腋窩神経損傷と腱板損傷は上腕骨近位部骨折。

第3部 下肢

4変形性股関節症と人工股関節

日本では80%が「二次性」

変形性股関節症は軟骨のすり減りと骨の変化で股関節が壊れていく病気。成人の股関節疾患で最多、40〜60歳代の女性に多く、日本では80%が二次性（寛骨臼形成不全など）。

症状

痛み・伸展と外転の制限・脚長差・跛行。爪切りや靴下をはくのが困難

病期

X線で前期・初期・進行期・末期の4期

治療

保存：減量・杖・水中歩行（免荷）。手術：骨切り術か人工関節

人工股関節術後の脱臼肢位

脱臼肢位は術前から指導する。浴槽は非術側から入る。しゃがむときは術側を外転・膝伸展に。

股関節の病気でみられる歩き方

診察ではパトリックテスト・トーマステストなども使う。

リハとリスク管理

項目ポイント
保存療法生活指導が中心。ストレッチ・筋力訓練、免荷できる水中歩行
術後の筋力低下しやすい股関節外転筋と膝伸展筋を中心に
歩行平行棒 → 歩行器 → 杖 → フリーハンドと段階的に
DVTDダイマー・ホーマンズ徴候（膝伸展で足を背屈 → ふくらはぎの痛み）・下肢の浮腫
感染CRP・創部の腫脹・熱感
退院前しゃがみ込み・浴槽の出入りを練習。家屋訪問で浴槽を確認

つながり

片脚立位で外転筋は体重の約4倍の力を出す（運動学）。外転筋が弱いとトレンデレンブルグ徴候が出る。

テーマ5 大腿骨近位部骨折（人工骨頭も脱臼肢位に注意）

施術の場面で意識したいこと

  • 人工股関節の人は、進入法によって避ける肢位が違う。施術時の体位（側臥位で脚を組ませる・深く曲げるなど）が脱臼肢位にならないよう、本人に指導された内容を確かめる。
  • 術後の人のふくらはぎの痛み・腫れはDVTのサインのことがある。強くもまず、受診をすすめる。

見ないで言ってみよう

後方進入法と前方進入法の脱臼肢位は？

後方法＝屈曲・内転・内旋、前方法＝伸展・内転・外旋。

トレンデレンブルグ徴候とは？ 何を強化する？

患側で片脚立ちすると健側の骨盤が下がる。中殿筋（股関節外転筋）を強化する。

ノートにまとめる

要点
  • 40〜60歳代女性、80%が二次性、脚長差・跛行
  • 保存：減量・杖・水中歩行
  • 脱臼肢位：後方法＝屈曲・内転・内旋、前方法＝伸展・内転・外旋
  • 術後は外転筋・膝伸展筋、DVT（ホーマンズ徴候）・感染に注意

確認問題

人工股関節置換術（後方進入法）の脱臼肢位はどれか。

  1. 伸展・外転・外旋
  2. 伸展・内転・外旋
  3. 屈曲・内転・内旋
  4. 屈曲・外転・外旋
後方法は屈曲・内転・内旋。前方法は伸展・内転・外旋。

患側で片脚立ちしたとき健側の骨盤が下がる現象はどれか。

  1. トレンデレンブルグ徴候
  2. デュシェンヌ徴候
  3. ホーマンズ徴候
  4. パトリックテスト陽性
中殿筋（外転筋）の弱化による。体幹を患側に傾けるのはデュシェンヌ徴候。

日本の変形性股関節症の約%は寛骨臼形成不全などによる二次性である。

40〜60歳代の女性に多い。

第3部 下肢

5大腿骨近位部骨折

高齢者の転倒で起こる代表的な骨折

大腿骨近位部骨折は年間約20万人で増加中（2040年に32万人と予測）。男女比1：3、70歳代から急増する。頚部骨折か転子部骨折かで治療が変わる。

殿部・大腿・鼠径部の痛み。転位のない骨折では歩いて受診することもある。

頚部骨折と転子部骨折

画像挿入スペース：大腿骨近位部の骨折部位の図正確性を確認できる図（教科書の図など）を挿入する場所です。

リハの要点

早期離床

手術翌日からギャッジアップ → 端座位。初めての座位はバイタル・顔色を確認

筋力

自動介助 → 抵抗運動。股関節周囲筋と膝伸展筋を中心に

荷重

平行棒内で慎重に。荷重制限は体重計2台で視覚的に学ぶ

リスク管理

リスク対応
DVT術前から足関節の底背屈の自動運動、弾性ストッキング・間欠的空気圧迫法
脱臼人工骨頭では変形性股関節症の術後と同じく脱臼肢位に注意
転位荷重を増やす時期は転位に注意
腓骨神経麻痺手術待機中の牽引で起こりうる
骨頭壊死術後も痛みが続くなら疑う

つながり

テーマ4 脱臼肢位 テーマ1 守ると動かす

施術の場面で気づきたいこと

  • 高齢者が転倒後に股関節〜鼠径部の痛みを訴えたら、歩けていても骨折の可能性がある。施術せず受診をすすめる。
  • 術後の人の階段や段差は「昇りは健側から・降りは患側から」が基本。本人が指導された方法を守れているか見守る。

見ないで言ってみよう

頚部骨折（転位型）で人工骨頭置換術が選ばれる理由は？

骨頭を養う内側大腿回旋動脈が損傷されやすく、骨癒合が得にくいため。

階段の2足1段のルールは？

昇りは健側から、降りは患側から。

AISで完全麻痺（A）と判定する条件は？

S4/S5の運動・感覚が完全に失われていること。

自律神経過反射はどの高さ以上の損傷で起こり、どう対応する？

T5〜T6以上。座位にして、尿や便の貯留など原因を除去する。

座位での褥瘡予防の除圧の頻度は？

15分ごとのプッシュアップ。

ノートにまとめる

要点

  2. 降圧のため冷水を飲ませる

  1. C4

  3. C8

13関節リウマチ

滑膜の炎症が続いて、関節が壊れる

関節リウマチは滑膜の炎症が続いて関節が壊れる自己免疫疾患。早く治療して3〜6か月で寛解に持ち込む。リハは炎症の強さで内容を変える。

疫学

有病率0.5〜0.6%（70万人以上）、男女比1：4、ピークは50歳代

症状

朝のこわばり・手指の多発関節炎・左右対称

診断

ACR/EULAR 2010分類基準で6点以上

進み方と変形

スタインブロッカー分類

Stage（Ⅰ〜Ⅳ）は関節破壊の程度で、Ⅳは線維性または骨性の強直。Class（Ⅰ不自由なし〜Ⅳ寝たきり・車いす）は日常生活の自立度。

治療の4本柱

時期に合わせたリハ

時期ポイント
急性期（活動性が高い）炎症が落ち着くまで強い負荷は避ける。関節保護・変形予防の装具。それでも安静にしすぎずROM訓練
炎症が落ち着いたら全身の関節のROM、筋力・持久力訓練。持久力は関節に優しいサイクリング・水中歩行
作業療法手芸・書道・パソコンで手指機能を維持。使いにくければ自助具
生活期長時間の同じ動作を避け、変形しやすい関節に負荷を集中させない。患者教育

リスク：動かしすぎで炎症が悪化。間質性肺疾患・心筋梗塞・心不全の合併にも注意。

つながり

尺側偏位・ボタン穴・スワンネック変形（運動学）、プラットフォームクラッチ（治療学）とつなげよう。

テーマ12 切断

施術の場面で意識したいこと

  • 関節に腫れ・熱感があるときは炎症が強い時期。温めず、強い刺激や無理な関節操作を避ける。
  • 環軸椎亜脱臼のおそれがあるため、首を強く曲げたりひねったりする操作をしない。
  • 手指に変形・痛みがある人は、物の受け渡しや着替えに時間がかかる。急かさず、関節に負担の少ない方法を一緒に考える。

14スポーツ傷害

「くり返し」か「1回の大きな力」か

スポーツ傷害は、くり返しの負荷で起こるスポーツ障害（慢性）と、1回の大きな力で起こるスポーツ外傷（急性）に分かれる。外傷の応急処置はRICE。

代表的なスポーツ障害

障害ポイント
離断性骨軟骨炎成長期に軟骨下骨が壊死して離れる。肘（上腕骨小頭・投球）・膝（サッカー）。原因スポーツの中止・安静
上腕骨外側上顆炎テニス肘。伸筋群の腱の炎症、女性に多い。雑巾しぼり・重い物の持ち上げで痛む。トムセンテスト・テニス肘バンド。約6か月以内に軽快
野球肘内側型（リトルリーグ肘・小学生）・外側型（離断性骨軟骨炎）・後方型。投球禁止 → 徐々に再開、投球フォームの矯正
脊椎分離症関節突起部の疲労骨折、10歳代。後屈で痛みが増強（ヘルニアは前屈で増強）。急性期はコルセットで骨癒合を目指す
疲労骨折肋骨・脛骨・第2・3中足骨。脛骨の中央型（ジャンプ）は難治性。初期はX線で写らない → MRI・骨シンチ

スポーツ外傷と応急処置

肉ばなれ

ダッシュでハムストリングス・大腿四頭筋、ジャンプで腓腹筋

筋挫傷

コンタクトスポーツで大腿四頭筋

施術の場面で意識したいこと

  • 成長期の選手の「投げると肘が痛い」「反ると腰が痛い」は、離断性骨軟骨炎・野球肘・脊椎分離症のことがある。痛みをがまんさせず受診をすすめる。
  • 疲労骨折は初期にX線で写らないことがある。同じ場所の運動時痛が続くときは、画像で異常がないと言われていても注意する。
  • 受傷直後はRICE。腫れている部位を温めたり強くもんだりしない。

整形外科疾患の全体地図

どの病気も「何を守り、何を動かすか」と「神経のどの高さか」で整理できる。病名から、守るもの・動かすもの・避ける動作を思い出そう。

テーマをまたいで思い出す

「前屈で痛い」「後屈で痛い」「前屈で楽」。それぞれどの病気？

前屈で痛い＝腰椎椎間板ヘルニア、後屈で痛い＝脊椎分離症（狭窄症も後屈で悪化）、前屈で楽＝腰部脊柱管狭窄症。

数字で覚える「やってはいけない期間」を3つ。

腱板縫合術後3か月は5kg以上を持たない、アキレス腱縫合術後6〜8週は腱を伸ばさない、人工股関節（後方法）は2〜3か月過屈曲を避ける。

DVTを防ぐために、多くの術後で共通して行うことは？

早期離床と、術前からの足関節の底背屈運動（弾性ストッキング・間欠的空気圧迫も）。

感覚がない・鈍い部位で施術者が特に気をつけることは？ どの病気で？

圧迫や熱による皮膚損傷・熱傷・褥瘡。脊髄損傷の麻痺域、糖尿病の足など。
