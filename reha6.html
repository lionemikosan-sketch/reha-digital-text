1リハビリテーション診断

活動の「いま」と「これから」をつかむ

リハビリテーション診断とは、症状や検査をリハ医学の知識と照らし合わせて活動の現状と問題点をつかみ、活動の予後を予測すること。

予後予測で大切な情報

機能障害

傷病名から想定される機能障害を正確に把握することが要

病前のADL

もともとどれくらい自立していたか

家族の介護力

家で誰が、どれくらい支えられるか

性格

意欲や取り組み方にかかわる

医療面接ではICFの各レベル（心身機能・活動・参加・環境・個人）を意識して情報を集める。

診療はくり返すサイクル

つながり

診断・治療・支援の3つはリハビリテーション医療で学んだ。ここでは「診断」の中身を詳しく見る。

2ゴールと意思決定・処方

目標は「SMART」に、本人とともに決める

ゴールはSMART（具体的・測れる・達成できる・本人に重要・期限がある）に立てる。リハで最も使われる決め方は共同意思決定（SDM）。

短期目標と長期目標、ニーズとデマンド

ニーズ

課題の解決に必要なこと

デマンド

患者の要望・希望。ニーズと一致しないことが多い → 希望を理解したうえでニーズを把握する

場面に合った意思決定

意思決定支援の優先順位：①表出された意思 → ②意思と選好に基づく最善の解釈 → ③最善の利益（最後の手段）。

処方とカンファレンス

処方箋から読む5つ

診断情報・治療目標・治療法（適応・禁忌）・頻度回数・特記事項。疑問は面倒がらず医師に確認

単位

1単位＝20分。入院中は1日6単位まで、回復期リハ病棟は9単位まで

カンファレンス

各職種が対等に話せる心理的安全性が肝心。患者・家族にはわかりやすい言葉で

つながり

テーマ1 リハ診断 テーマ3 評価の考え方

施術者とのかかわり

  • 教科書には、あん摩マッサージ指圧師は特定の条件を満たせば、リハビリテーション処方に基づくリハ治療を実施できる場合がある（いわゆる「みなしPT」）と記されている。
  • 施術の目標もSMARTに立てると、本人と共有しやすく、効果も確かめやすい。

見ないで言ってみよう

SMARTの5つは？

Specific（具体的）・Measurable（測れる）・Achievable（達成できる）・Relevant（本人に重要）・Time-bound（期限がある）。

超急性期・認知症の人・生命予後が限られる人の意思決定は？

超急性期＝パターナリズム、認知症など＝意思決定支援、生命予後が限られる人＝ACP。

ノートにまとめる

要点
  • SMART、STG約2週間・LTG約2〜3か月
  • ニーズ（必要）とデマンド（希望）
  • パターナリズム・IC・SDM（最多）・意思決定支援・ACP
  • 1単位20分、入院6単位、回復期9単位

確認問題

リハビリテーション医療で最も使われる意思決定の手法はどれか。

  1. パターナリズム
  2. 共同意思決定
  3. ACP
  4. 意思決定支援
患者と医療者がともに決める共同意思決定（SDM）。

リハの1単位は分で、回復期リハ病棟では1日単位まで実施できる。

一般の入院は1日6単位まで。

第1部 診断と評価の考え方

3評価の考え方

集めて、考えて、計画して、試して、また評価する

評価は収集 → 分析 → 計画 → 実施 → 再評価のくり返し。治療プログラムは「筋力増強訓練」ではなく、具体的に書く。

情報を集める4つの方法

観察

表面的（形態）と内面的（表情から心理）、局所と全体

面接

医療面接（問診）

検査

一定の基準で判定する（腱反射・運動発達検査など）

測定

数量化する（ROM・筋力・形態計測）

定性的評価（ある・ない、特徴を文章で）と定量的評価（数量化）がある。プログラムは機器・肢位・部位・回数・強度まで書く（例：腹臥位で徒手抵抗、30回）。

数字の種類で、できる計算が変わる

MMTの「4」は「2」の2倍強いわけではない → 順序尺度。尺度によって統計処理や解釈が変わる。

つながり

テーマ6 MMT（順序尺度） テーマ5 ROM（角度＝比率尺度）

見ないで言ってみよう

4つの尺度と例は？

名義（性別）・順序（MMT・バーセル指数）・間隔（摂氏温度）・比率（長さ・質量・角度）。

「検査」と「測定」の違いは？

検査＝基準による判定（陽性／陰性など）、測定＝数量化（ROM・筋力など）。

ノートにまとめる

要点
  • 収集（観察・面接・検査・測定）→ 分析 → 計画 → 実施 → 再評価
  • 名義・順序・間隔・比率尺度
  • MMT・バーセル指数は順序尺度、角度・長さは比率尺度

確認問題

MMTの段階はどの尺度にあたるか。

  1. 名義尺度
  2. 順序尺度
  3. 間隔尺度
  4. 比率尺度
順序には意味があるが、間隔に意味がない。

絶対零点をもち比率にも意味がある尺度の例はどれか。

  1. 性別
  2. 摂氏温度
  3. バーセル指数
  4. 関節の角度
長さ・質量・速度・角度は比率尺度。摂氏温度は間隔尺度。

第2部 測る

4形態計測

同じ「足の長さ」でも、測り方で意味が違う

四肢の長さと周径を測り、左右差から骨折・拘縮・筋萎縮・浮腫などを推測する。

四肢長と周径の測る位置

項目測る位置意味
上肢長肩峰 → 橈骨茎状突起（または第3指先端）左右差で拘縮・骨折
棘果長上前腸骨棘 → 内果下肢長（骨盤〜足）
転子果長大転子 → 外果下肢長（大腿骨頭の問題は含まない）
大腿長／下腿長大転子 → 大腿骨外側上顆／外側上顆 → 外果
上腕周径肘伸展位と屈曲位（力こぶ）差が小さい → 上腕二頭筋の萎縮
下腿周径最大部・最小部（両果の直上）筋萎縮・浮腫
画像挿入スペース：計測点（骨指標）の図正確性を確認できる図（教科書の図など）を挿入する場所です。

大腿周径は高さで意味が変わる

つながり

脚長差は変形性股関節症の症状（整形外科疾患）。下腿周径の左右差は浮腫の手がかりにもなる。

テーマ5 関節可動域テスト

施術の場面で生かす

  • 膝の痛みが続く人の大腿周径（膝蓋骨上縁から5・10cm）を左右で比べると、内側・外側広筋のやせ具合を数字で確かめられる。
  • 周径や長さは同じ骨の指標で測ってこそ比べられる。測った位置を記録しておく。

見ないで言ってみよう

棘果長と転子果長は、どこからどこまで？

棘果長＝上前腸骨棘 → 内果、転子果長＝大転子 → 外果。

大腿周径の0cm・5/10cm・15/20cmが表すものは？

0cm＝関節腫脹、5・10cm＝内側・外側広筋、15・20cm＝大腿全体の筋。

ノートにまとめる

要点
  • 棘果長＝上前腸骨棘→内果、転子果長＝大転子→外果
  • 上腕周径は伸展位と屈曲位の差
  • 大腿周径：0cm腫脹・5/10cm広筋・15/20cm大腿全体
  • 下腿周径：筋萎縮・浮腫

確認問題

棘果長の計測点はどれか。

  1. 大転子 → 外果
  2. 大転子 → 内果
  3. 上前腸骨棘 → 内果
  4. 上前腸骨棘 → 外果
棘果長は上前腸骨棘から内果。転子果長は大転子から外果。

大腿周径で膝蓋骨上縁から5cm・10cmの値は、内側広筋・の萎縮を反映する。

0cmは関節腫脹。

第2部 測る

5関節可動域テスト（ROM-T）

決まった方法で、他動的に、5°刻みで

関節可動域テストは、障害の有無と程度を知り、最終域感（end feel）から制限の原因を推測し、ADLの制限や治療効果を判断するために行う。

主な参考可動域

部位参考可動域
肩屈曲180・伸展50・外転180・外旋60・内旋80
肘・前腕肘屈曲145・伸展5／回内・回外90
手掌屈90・背屈70・橈屈25・尺屈55
股屈曲125・伸展15・外転45・内転20・外旋45・内旋45
膝・足膝屈曲130・伸展0／足背屈20・底屈45
頚・胸腰頚屈曲60・伸展50・回旋60／胸腰屈曲45・伸展30
画像挿入スペース：角度計の当て方の図正確性を確認できる図（教科書の図など）を挿入する場所です。

つながり

拘縮と強直・ROM訓練は治療学、良肢位は運動学で学んだ。角度は比率尺度。

テーマ3 評価尺度 テーマ6 MMT

施術の場面で生かす

  • 施術前後で同じ方法（他動・同じ肢位）で角度を測ると、変化を客観的に示せる。
  • 動かしたときの最終域での抵抗感（最終域感）にも注意を向け、痛みの有無を記録する。

見ないで言ってみよう

ROM測定の原則（自動か他動か・刻み・0°の基準）は？

原則他動運動、5°刻み、基本肢位を0°とする。

肩の外旋・内旋、手の背屈、足の背屈・底屈の参考可動域は？

肩外旋60・内旋80、手背屈70、足背屈20・底屈45。

ノートにまとめる

要点
  • 原則他動、自動なら明記、基本軸と移動軸、5°刻み、基本肢位0°
  • 最終域感から制限因子を推測
  • 肩屈曲180・外旋60・肘屈曲145・手背屈70
  • 股屈曲125・膝屈曲130・足背屈20・底屈45

確認問題

関節可動域測定について正しいのはどれか。

  1. 原則として他動運動で測る
  2. 1°刻みで読む
  3. 自動で測っても記録の必要はない
  4. 痛みは記録しない
原則他動・5°刻み。自動で測った場合はその旨と痛みも記録する。

足関節の参考可動域は背屈°、底屈°である。

膝関節屈曲位で測る。

第2部 測る

6徒手筋力テスト（MMT）

重力に勝てるかどうかが「3」の境目

徒手筋力テスト（MMT・ダニエルス法）は筋力を0〜5の6段階で判定する。3は重力に抗して全可動域を動かせる、2は重力を除けば動かせる。

ルールと例外

＋・−

原則つけない（例外：2−）

ブレイクテスト

最終域付近で抵抗をかけ、保持を打ち破る

足関節底屈

片脚つま先立ち25回以上で5、2〜24回で4、1回で3

対象

末梢性の弛緩性麻痺・廃用。片麻痺には向かない

MMT以外の筋力評価：握力（全身の筋力と関連）・背筋力・脚筋力。

つながり

MMTの段階で運動の種類（他動・自動介助・自動・抵抗）を選ぶことは治療学で学んだ。片麻痺の評価はテーマ13。

テーマ13 片麻痺の評価 テーマ3 順序尺度

施術の場面で生かす

  • 筋力低下の訴えがあれば、MMTで左右差や段階を確かめると、末梢神経の問題などを考える手がかりになる。急な筋力低下は受診をすすめる。

見ないで言ってみよう

MMTの5〜0の判定基準を言えますか？

5＝最大抵抗に抗して保持、4＝強〜中等度の抵抗、3＝重力に抗して全可動域、2＝重力を除けば全可動域、1＝収縮のみ、0＝収縮なし。

片麻痺の評価にMMTが向かないのはなぜ？

片麻痺は筋力（量）でなく運動様式（質）の変化だから。

ノートにまとめる

要点
  • 5 Normal・4 Good・3 Fair（抗重力）・2 Poor（重力除去）・1 Trace・0 Zero
  • 3以上は抗重力位、2以下は重力を除いた肢位
  • +−は原則つけない（2−は例外）、ブレイクテスト
  • 足底屈は片脚つま先立ち25回以上で5
  • 片麻痺には向かない

確認問題

MMT3の判定基準はどれか。

  1. 収縮はあるが関節は動かない
  2. 重力を除けば全可動域を動かせる
  3. 重力に抗して全可動域を動かせる
  4. 中等度の抵抗に抗して保持できる
3 Fair＝重力に抗して全可動域。

足関節底屈のMMTでは、片脚つま先立ちが回以上できれば5と判定する。

2〜24回で4、1回で3。

第3部 調べる

7整形外科的検査（上半身）

何をすると、どこが痛むか

整形外科的検査は、特定の姿勢や動作でどこに症状が出るかを見て、病気を推測する。検査の「しくみ」（何を狭め、何を伸ばすか）とセットで覚える。

やり方と陽性所見

検査やり方陽性 → 疑う病気
スパーリング頚椎を後屈＋側屈して頭を下に圧迫側屈側の上肢に放散痛 → 頚椎神経根症
ジャクソン頚椎を後屈して頭を下に圧迫上肢に放散痛 → 頚椎神経根症
アドソン橈骨動脈を触れ、頚部後屈＋検査側へ回旋＋深吸気拍動の減弱・消失 → 胸郭出口症候群
ペインフルアーク自動で外転60〜120°だけ痛む → 腱板損傷・インピンジメント
ヤーガソン肘90°・回内位から回外に抵抗結節間溝の痛み → 上腕二頭筋長頭腱炎
トムセン手関節背屈を保たせ、掌屈方向へ力を加える外側上顆の痛み → テニス肘
ファーレン両手の手背を合わせ手関節最大屈曲1分母指〜中指のしびれ → 手根管症候群

9神経学的検査（感覚・反射）

反射が「強い」のは上の障害、「弱い」のは反射弓の障害

感覚検査と反射検査で、神経のどこが障害されているかを推測する。深部腱反射の亢進は中枢より上（錐体路）、減弱・消失は反射弓そのもの（末梢神経など）の障害。

感覚検査

目的

やり方

閉眼で。四肢は長軸に平行、体幹は肋骨に平行に。左右対称に比べ、健側を10点として採点（0＝消失）

40〜45℃の温水と5〜10℃の冷水の試験管を約3秒、ランダムに当てる

主な腱反射の中枢

記録は（−）消失〜（＋）正常〜（卌）著明な亢進。表在反射は多シナプス反射で、錐体路障害で減弱・消失する。

病的反射：健常成人では出ない

つながり

13片麻痺の評価

片麻痺は「量」でなく「質」の変化

末梢神経麻痺は筋力低下という量の変化だが、片麻痺は運動様式（質）の変化。だからMMTでは正確に評価できず、ブルンストローム・リカバリーステージ（BRS）などを使う。

ほかにFugl-Meyer assessment（FMA）・12段階片麻痺機能検査。BRSは日本で最も広く使われ、上肢・手指・下肢それぞれを評価する。

BRSの6段階

連合反応と共同運動

連合反応

ある部位の運動で他の部位に筋収縮が起こる。対側性：非麻痺肢の運動で麻痺肢が動く。同側性：麻痺側上肢の運動で同側下肢が動く

共同運動

一肢の屈筋群・伸筋群がまとめて働き、ばらばらに動かせない

つながり

BRS Ⅰ〜Ⅲで膝が伸ばせなければ長下肢装具、のように、評価が治療につながる（神経・内部障害）。

テーマ6 MMT テーマ12 筋緊張

施術の場面で生かす

  • 片麻痺の人では、どの段階か（共同運動しかできないか、分離運動ができるか）を知ると、動作の介助や声かけの工夫がしやすい。

見ないで言ってみよう

BRSⅠ〜Ⅵを順に言えますか？

Ⅰ随意運動なし → Ⅱ連合反応・共同運動が一部 → Ⅲ共同運動が随意的に（痙縮最強）→ Ⅳ分離運動が一部 → Ⅴ分離運動が全般的に → Ⅵ分離運動が自由に。

上肢の屈筋共同運動と下肢の伸筋共同運動の形は？

MMT・バーセル指数・関節の角度は、それぞれ何尺度？

MMT・バーセル指数＝順序尺度、角度＝比率尺度。

SLRテストで陽性の人。どの腱反射を見ると、神経根の高さを確かめやすい？

SLRはL4〜S1。アキレス腱反射（主にS1）の減弱・消失を確かめる。膝蓋腱反射はL2〜L4。

片麻痺の評価にMMTではなくBRSを使い、痙縮はMASで評価する理由は？

片麻痺は筋力（量）でなく運動様式（質）の変化だから。痙縮は他動運動時の抵抗感で評価する。
