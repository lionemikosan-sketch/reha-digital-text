第1部 運動療法

1ROMと拘縮

動かさないと、関節は固まる

3週間以上動かさないと関節可動域（ROM）の制限がはっきり現れ、8週間以上の固定では元に戻らない（不可逆的な）変化が起こる。

拘縮と強直

拘縮

皮膚・筋・関節包など軟部組織が原因のROM制限

強直

骨・軟骨が原因のROM制限

神経性拘縮の3つ

反射性：痛みを避けて逃避の肢位を長くとる。痙性：中枢神経の病変による痙性麻痺・筋緊張亢進。弛緩性：脊髄・末梢神経の病変による弛緩性麻痺。

ROM訓練の種類

制限の原因を評価し、患者の状態に応じて使い分ける。最終域で感じる抵抗（最終域感）から、制限因子を推測する。

どのくらい、どう動かすか

目安：1関節を3〜5回、1日2回程度。

注意：急に動かすと痛みを誘発し、筋緊張が高まる。強引な操作は異所性骨化の原因にもなる。

つながり

良肢位（運動学）は、ROM制限が残っても生活に困りにくい角度。急性期の早期離床は、不動による合併症を防ぐ。

テーマ2 筋力訓練へ

施術の場面で意識したいこと

  • 関節を他動的に動かすときは、ゆっくり行い、痛みを誘発しない範囲にとどめる。急な操作は筋緊張を高める。
  • ギプス固定などで長く動かしていない関節は、ROM制限が起こっていることを前提に扱う。

見ないで言ってみよう

拘縮と強直の違いは？

拘縮＝軟部組織が原因、強直＝骨・軟骨が原因のROM制限。

ROM制限がはっきり出る不動期間と、不可逆的になる固定期間は？

3週間以上の不動でROM制限が顕著、8週間以上の固定で不可逆的。

Hoffa分類の5つは？

皮膚性・結合組織性・筋性・神経性・関節性。

ノートにまとめる

要点
  • 拘縮＝軟部組織、強直＝骨・軟骨
  • 3週間でROM制限、8週間以上の固定で不可逆
  • 他動・自動介助・自動ROM訓練、CPM
  • 1関節3〜5回・1日2回程度。急に動かすと痛み・筋緊張亢進・異所性骨化

確認問題

軟部組織が原因で起こる関節可動域制限はどれか。

  1. 強直
  2. 拘縮
  3. 脱臼
  4. 骨折
拘縮は軟部組織、強直は骨・軟骨が原因。

長期間の関節固定による筋の短縮・萎縮が原因の拘縮はどれか。

  1. 皮膚性拘縮
  2. 関節性拘縮
  3. 神経性拘縮
  4. 筋性拘縮
筋性拘縮。皮膚性は熱傷などの瘢痕、関節性は滑膜・関節包の炎症など。

ROM訓練は1関節を3〜回、1日回程度行う。

急に動かすと痛みを誘発し、筋緊張亢進や異所性骨化の原因になる。

ROM訓練で関節を急激に動かしてはいけない理由を説明しよう。

模範解答例：痛みを誘発して筋緊張が高まり、かえって動かしにくくなる。また異所性骨化の原因にもなるため。

第1部 運動療法

2筋力・持久力の訓練

筋力をつけるには「一定以上」の負荷が必要

筋力増強には最大筋力の40〜60%以上の強度が必要。維持するだけなら20〜30%。目的によって強さと回数を変える。

筋力増強の3原則

筋持久力訓練は低負荷・高頻度が原則。最大筋力の20〜40%（30〜50回くり返せる負荷）が最適ともいわれる。

筋力の段階（MMT）で運動の種類を選ぶ

運動やり方適応（MMT）
他動運動セラピストが関節を動かす0以上
自動介助運動患者が筋を収縮させ、セラピストが手伝う1か2以上
自動運動患者自身で動かす3以上
抵抗運動徒手や機器で抵抗をかける4・5

収縮のしかたで分けた訓練

等張性

PRE（漸増抵抗）とRRE（漸減抵抗）。10RMを基準にする

等尺性

4〜6秒の最大等尺性収縮。ギプス固定中など関節を動かせないときに。血圧が上がるので息を止めない

等速性

特殊な機器で角速度を設定。低速＝筋力、高速＝筋持久力

つながり

等張性・等尺性・等速性、求心性・遠心性は運動学で学んだ筋収縮の分け方。MMTは身体評価学で詳しく学ぶ。

テーマ1 ROM訓練

施術の場面で意識したいこと

  • セルフケアとして筋力運動をすすめるとき、力を込めて止める運動（等尺性）では息を止めないよう伝える。血圧が上がるため。
  • 運動をやめると筋力は失われる（可逆性）。続けられる負荷と回数を一緒に考える。

見ないで言ってみよう

筋力の増強・維持・すべての筋線維の動員に必要な強度は？

増強＝40〜60%以上、維持＝20〜30%、すべての筋線維＝70〜80%以上。

MMT2・3・4の人に適した運動は？

MMT2＝自動介助運動、MMT3＝自動運動、MMT4＝抵抗運動。

PREの負荷の上げ方は？

10RMを測り、その50% → 75% → 100%と増やす。

ノートにまとめる

要点
  • 過負荷・特異性・可逆性の3原則
  • 増強40〜60%以上、維持20〜30%、持久力20〜40%（低負荷・高頻度）
  • MMT0〜：他動、1・2：自動介助、3：自動、4・5：抵抗
  • PRE（50→75→100%）・RRE（10%ずつ減らす）、等尺性は4〜6秒で息を止めない
  • OKC＝非荷重位、CKC＝荷重位

確認問題

MMT3の筋に適した運動はどれか。

  1. 他動運動
  2. 自動介助運動
  3. 自動運動
  4. 抵抗運動
MMT3以上で自動運動。4・5で抵抗運動、1・2で自動介助運動。

等尺性筋力増強訓練で注意すべきことはどれか。

  1. 血圧の上昇
  2. 関節の脱臼
  3. 体温の低下
  4. 異所性骨化
最大等尺性収縮では血圧が上がる。息を止めずに行う。

筋力を維持するには最大筋力の20〜%の強度が必要である。運動をやめると筋力が失われることをの原則という。

増強には40〜60%以上が必要（過負荷の原則）。

特異性の原則にもとづき、筋力訓練と筋持久力訓練の違いを説明しよう。

模範解答例：目的に合わせて方法を変える。筋力は高負荷・低頻度、筋持久力は低負荷・高頻度・長時間で行う。

3協調性訓練と治療体操

動作を「分けて」くり返し、またつなぐ

協調性とは、姿勢を安定させ、動作を目的どおり円滑に行うための調節機能。動作を相に分けて練習し、最後に全体を通して行う。

協調性訓練の代表的な方法

フレンケル体操

視覚で代償しながら、簡単な動きから複雑な動きへ

重錘負荷

四肢の末梢に軽いおもりをつける

弾性緊迫帯

下部体幹・股関節周囲に弾性包帯を巻く

特殊な運動療法と治療体操：名前とねらいをセットで

名前ねらい・対象
PNF（固有受容性神経筋促通法）中枢性疾患から運動器疾患・スポーツ傷害まで幅広く
ブルンストローム法共同運動の分離で回復を図る
ボバース法筋緊張の正常化を目指す
CI療法非麻痺側を抑え、麻痺肢の使用を強制する
促通反復療法（川平法）意図した運動をくり返す
バイオフィードバック筋電図などを見て・聴いて制御する
ウィリアムズ体操・マッケンジー体操腰痛体操（マッケンジー体操は腹臥位で伸展）
コッドマン体操五十肩など肩関節（振り子運動）
バージャー体操バージャー病の血行改善
ベーラー体操脊柱のアライメント保持

つながり

動作を「認知 → 連合 → 自動化」と身につける運動学習の考え方が、協調性訓練の土台にある。

第1部 運動療法

4杖歩行

支える点が多いほど安定し、少ないほど速い

杖歩行は、いつも何点で体を支えているかで安定性と速さが決まる。安定を取るか、速さを取るかは本人の能力に合わせて選ぶ。

松葉杖歩行（両側）

歩き方方法特徴・対象
4点歩行左杖 → 右足 → 右杖 → 左足常に3点以上で支持：最も安定・遅い
2点歩行一側の杖と反対側の足を同時に速いが、4点歩行より不安定
3点歩行両杖と患足を同時に → 健足一側下肢障害。患足は部分荷重
大振り歩行両杖を出し、両下肢を杖を結ぶ線より前へ脊髄損傷（ジャックナイフ肢位）
小振り歩行両杖を出し、両下肢を杖を結ぶ線より後ろへ脊髄損傷、骨盤挙上筋が残っている人

片側杖の歩き方

健脚の着地位置は、後ろ型 → 揃え型 → 前型の順に難しくなる。練習は3動作の後ろ型から2動作の前型へ、能力に合わせて選ぶ。

つながり

杖は支持基底を広げて重心線を支持基底内に収める道具。杖の種類と長さの合わせ方はテーマ10で学ぶ。

テーマ10 杖の種類と合わせ方

施術の場面で意識したいこと

  • 杖を使う人の移動を介助するときは、本人が指導されている歩き方（3動作か2動作か）に合わせ、急がせない。
  • 片側杖は原則として健側の手で持つ。施術室の出入りや段差では、杖と患脚の順番を守れているか見守る。

見ないで言ってみよう

最も安定する松葉杖歩行と、その順番は？

4点歩行：左杖 → 右足 → 右杖 → 左足。常に3点以上で支える。

一側下肢障害で使う松葉杖歩行は？

3点歩行（両杖と患足を同時に出し、次に健足）。

3動作歩行と2動作歩行の順番と特徴は？

3動作＝杖 → 患脚 → 健脚、安定・遅い。2動作＝杖と患脚を同時に → 健脚、速いが安定性は低い。

ノートにまとめる

要点
  • 4点歩行：最も安定・遅い／2点歩行：速いが不安定
  • 3点歩行：一側下肢障害（患足は部分荷重）
  • 大振り（杖の線より前）・小振り（後ろ）：脊髄損傷
  • 片側杖：3動作（杖→患→健）は安定、2動作（杖＋患→健）は速い
  • 健脚の位置：後ろ型 → 揃え型 → 前型の順に難しい

確認問題

松葉杖歩行で最も安定性が高いのはどれか。

  1. 4点歩行
  2. 2点歩行
  3. 3点歩行
  4. 大振り歩行
4点歩行は常に3点以上で支持するため最も安定するが、遅い。

両下肢を松葉杖を結ぶ線より前方に着く歩き方はどれか。

  1. 小振り歩行
  2. 3点歩行
  3. 大振り歩行
  4. 4点歩行
大振り歩行。後方に着くのが小振り歩行。どちらも脊髄損傷などで用いる。

片側杖の常時2点支持歩行（3動作歩行）は、杖 → → の順に出す。

安定性がよいが速度は遅い。

2動作歩行が3動作歩行より速いが不安定な理由を、支持する点の数から説明しよう。

模範解答例：2動作歩行は杖と患脚を同時に出すため動作の回数が少なく速い。しかし健脚1点だけで支える瞬間があるため、常に2点で支える3動作歩行より不安定になる。

第2部 物理療法

5物理療法

熱・冷・電気・水・光を体に与える

物理療法は、温熱・寒冷・電気・水・牽引・光線などの物理的エネルギーを生体に与える治療。効果と同じくらい禁忌を覚えることが大切。

温熱療法：届く深さで2つに分かれる

表在性温熱深達性温熱
例ホットパック・パラフィン・温水浴・赤外線超短波・極超短波・超音波
特徴浮腫軽減・筋スパズム寛解・血流改善・瘢痕の軟化筋など深部を加熱、衣服の上からも可能
禁忌感覚麻痺・開放創・炎症部位・妊婦ペースメーカー・体内金属（超短波・極超短波）・出血傾向・眼球・悪性腫瘍・妊婦

適応：変形性関節症・肩関節周囲炎・関節リウマチ・変形性脊椎症・外傷後慢性期の疼痛など。

寒冷療法：冷やすと、あとで血流が増える

適応

打撲・捻挫の応急処置、急性期の炎症、局所の疼痛、有痛性筋スパズム、競技直後のアイシング

禁忌

寒冷過敏症、レイノー病・レイノー症候群、循環障害・末梢血管疾患、小児

その他の物理療法

療法ねらい・適応主な禁忌
プール心肺機能、水の抵抗で筋力、浮力で免荷心疾患・開放創・感染症・ストーマ・重い低血圧／高血圧
超音波組織の伸展性を高める・血流改善・疼痛緩和眼・成長期の骨端・心臓・生殖器・腫瘍・ペースメーカー
水治療法（渦流浴）温熱・血行改善・壊死組織の除去出血傾向・悪性腫瘍・急性炎症・感染症
牽引療法頚部〜腰背部の疼痛・こわばり脊椎炎・悪性腫瘍・関節リウマチ・骨粗鬆症・妊婦

レーザー創傷治癒・消炎・鎮痛悪性腫瘍・甲状腺・眼球・精巣

つながり

TENSは感覚神経を刺激して痛みを和らげる。FESは麻痺した筋を刺激して動作をつくる（運動の再建）。

テーマ2 筋力訓練

施術の場面で意識したいこと

  • 温熱の禁忌に感覚麻痺がある。熱さを感じにくい部位では熱傷が起こりやすいため、灸など熱を使う施術でも感覚の確認が欠かせない。
  • ペースメーカーや体内金属の有無は、深達性温熱や電気を使う機器の禁忌にかかわる。問診で必ず確かめる。
  • 打撲・捻挫の直後は寒冷が適応。急性期の炎症部位を温めない。

見ないで言ってみよう

表在性温熱と深達性温熱の例を2つずつ。

表在性＝ホットパック・パラフィン（温水浴・赤外線）。深達性＝超短波・極超短波（超音波）。

寒冷療法で血流が増えるしくみは？

血管収縮で代謝産物がたまり、ヒスタミン様物質が血管を拡張させて反応性充血が起こる。

TES・FES・TENSの違いは？

TES＝強い筋収縮、FES＝運動の再建（機能的電気刺激）、TENS＝感覚神経を刺激して鎮痛。

ノートにまとめる

要点
  • 表在性温熱：ホットパックなど。禁忌＝感覚麻痺・開放創・炎症部位
  • 深達性温熱：超短波など。禁忌＝ペースメーカー・体内金属
  • 寒冷：反応性充血。適応＝打撲・捻挫の応急処置。禁忌＝レイノー病・寒冷過敏症

  • TENS＝鎮痛、FES＝運動の再建

  4. 紫外線

第3部 作業療法・言語聴覚療法

6作業療法

「作業」は手芸や工作だけではない

作業療法は「人は作業を通して健康や幸福になる」という考え方にもとづく。作業とは、その人にとって目的や価値をもつ生活行為のこと。

生活行為には、ADL・IADL（家事など）・仕事・余暇・社会参加まで含まれる。トイレ・料理・仕事・趣味・町内会、すべてが作業になる。

作業療法でめざす3つの能力

定義の移り変わり

1965年の法律では、応用的動作能力・社会的適応能力の回復のために手芸・工作などを行うものとされた。2018年の新しい定義では、作業に焦点を当てた治療・指導・援助とされている。

作業の2つの使い方

あわせて、環境因子（自助具・住環境）に働きかけ、個人因子（興味・関心）を考えて作業の種目を選ぶ。

時期ごとの作業療法

回復期の例

具体的な目標を立て、電動義手の操作練習など

生活期の例

IADL・社会参加へ活動範囲を広げる。絵筆ホルダーの作製など

終末期の例

機能回復ではなく満足や価値（QOL）の視点。意思伝達装置で遺言を残す支援など

つながり

環境因子・個人因子はICFの背景因子。作業療法は「活動」「参加」に直接働きかける。

テーマ10 自助具

施術の場面で意識したいこと

  • 患者さんにとっての「作業」（大切にしている仕事・家事・趣味）を聞くと、施術の目標を本人の生活に結びつけやすい。

見ないで言ってみよう

作業療法でめざす3つの能力は？

基本的動作能力・応用的動作能力・社会的適応能力。

手段としての作業と目的としての作業の違いを例で。

手段＝心身機能の回復・維持に使う（サンディングボード・ペグボード）。目的＝その作業自体をできるように練習する（更衣練習）。

終末期の作業療法の視点は？

機能回復ではなく、患者の満足や価値（QOL）を高めること。

ノートにまとめる

要点
  • 作業＝目的や価値をもつ生活行為（ADL・IADL・仕事・余暇・社会参加）
  • 基本的動作能力・応用的動作能力・社会的適応能力
  • 手段としての作業／目的としての作業
  • 予防期〜終末期まで。終末期はQOLの視点

確認問題

作業療法で維持・改善をめざす能力に含まれないのはどれか。

  1. 基本的動作能力
  2. 応用的動作能力
  3. 最大筋力
  4. 社会的適応能力
3つの能力は基本的動作能力・応用的動作能力・社会的適応能力。

「目的としての作業」の例として適切なのはどれか。

  1. 更衣動作の練習
  2. サンディングボード
  3. ペグボード
  4. 重錘負荷
更衣練習は作業そのものをできるようにする目的としての作業。サンディング・ペグボードは手段としての作業。

「作業療法の作業＝手芸や工作」という考えは、なぜ不十分なのか説明しよう。

模範解答例：作業とはその人にとって目的や価値をもつ生活行為のことで、ADL・家事・仕事・趣味・社会参加まで含まれる。手芸や工作はその一部にすぎない。

第3部 作業療法・言語聴覚療法

7言語聴覚療法

ことば・きこえ・たべる

言語聴覚療法（ST）は、ことば（構音障害・失語症・吃音・音声障害）、きこえ（聴覚障害）、たべる（摂食嚥下障害）を支える。

言語障害は外見からわかりにくく誤解されやすい。STは本人だけでなく、話し相手である家族も支援する。

ことばの障害を見分ける

構音障害失語症
どこの障害話すための器官（呼吸・喉頭・口・舌）の動き言語野（多くは左半球）
症状音のひずみ・声が続かない・リズムの乱れ話す・聴く・書く・読むすべてが低下。仮名が苦手
伝え方書く・50音表で通じる50音表は使えない。漢字のほうがわかりやすい
関連脳血管障害・神経筋疾患・唇顎口蓋裂右片麻痺を伴うことが多い

きこえの障害

補う方法

補聴器（調整が必要）・人工内耳・手話・口話

話しかけ方

口を隠さず、やや大きめに口を動かす。誤解がないよう文字で示す

耳元で大声はNG

リクルーメント現象で、大きな音を不快に感じやすい。75歳ごろから加齢で聴力が低下する

食べる・飲み込むの5つの時期

つながり

失語症は言語野の多い左半球の障害なので、右片麻痺を伴いやすい。脳卒中のリハビリテーションで再び出てくる。

テーマ6 作業療法

施術の場面で意識したいこと

  • 難聴の人には、耳元で大声を出すのではなく、口元を見せてはっきり話し、必要に応じて文字で示す。

見ないで言ってみよう

失語症の人に50音表が使えないのはなぜ？

音声言語だけでなく文字言語も障害されるため（特に仮名が苦手）。

伝音難聴と感音難聴は、それぞれどこの障害？

伝音＝外耳・中耳、感音＝内耳〜聴神経。

先行期 → 準備期 → 口腔期 → 咽頭期 → 食道期。

ノートにまとめる

要点

確認問題

失語症について正しいのはどれか。

  1. 50音表で意思疎通ができる
  2. 仮名より漢字のほうが理解しやすい
  3. 左片麻痺を伴うことが多い
  4. 話す器官の運動障害である
失語症では文字言語も障害され、特に仮名が苦手。言語野は多くが左半球にあり右片麻痺を伴いやすい。

  1. 耳元で大声で話す
  2. 口元を隠して話す
  3. 早口で何度もくり返す
  4. 口を大きめに動かし文字でも示す
リクルーメント現象で大きな音を不快に感じやすい。口元を見せ、文字で示す。

外耳・中耳の障害による難聴をという。摂食嚥下の5期のうち、誤嚥が起こりやすいのはである。

第4部 義肢・装具・福祉用具

8義肢

失った手足を補う

義肢は、切断・離断で失った手足を補う。義手と義足があり、下腿義足は自分で膝を動かせるため、大腿義足より歩きやすい。

切断（狭義）

骨幹部・骨幹端部で切り離す

離断

関節部で切り離す（例：肩関節離断 → 肩義手、膝関節離断 → 膝義足）

義肢の分け方

殻構造

中空の殻で支える（外骨格）

骨格構造

パイプの支柱＋継手（内骨格）。部品が規格化され交換しやすい

ソケット

差し込み式（自己懸垂なし）／吸着式（断端より一回り小さく、陰圧で自己懸垂）

義足と義手の特徴

義肢特徴
下腿義足自分で膝をコントロールできる → 歩行・走行能力が高い。断端は長いほうが有利。ソケットはPTB（膝蓋腱で支持）
大腿義足膝のコントロールが難しく膝継手が重要（単軸：速い屈伸に反応／多軸：滑らかな屈伸）。四辺形ソケットは坐骨結節で体重支持
サイム義足内外果の遠位で切離。踵の皮膚で覆われ断端荷重が可能。断端が膨らみ外観は不良、懸垂は容易
足部SACH足が多い。活動性が高い人にはエネルギー蓄積型足部
義手練習は主に作業療法士（義足は理学療法士）。手先具は能動フック（多用途）・能動ハンド

つながり

ICIDHの例「下腿切断の作業員」を思い出そう。義足で歩けても、仕事に戻れるかは環境で変わる。

テーマ9 装具へ

切断と離断の違いは？

切断＝骨幹部・骨幹端部で切離、離断＝関節部で切離。

ノートにまとめる

要点
  • 切断＝骨幹部、離断＝関節部

10自助具・杖・車いす

「できない理由」に合わせて道具を選ぶ

自助具・歩行補助具・車いすは、残存能力・予後・使う場所・目的から選ぶ。過剰なサポートは、かえって本人の能力を下げる。

動作ごとの自助具

動作困りごと自助具の例
食事握れない・届かない／すくいにくい太柄スプーン・つまむのを助ける箸・BFO・PSB／壁のある皿・滑り止めマット・鼻に当たらないコップ
整容届かない／片手長柄の櫛・ホルダー付き歯ブラシ／片手用爪切り
更衣リーチが困難／ボタンが困難ソックスエイド・リーチャー／ボタンエイド
トイレ立ち座りが困難補高便座・昇降便座・尻ふき器
入浴洗えない／浴槽の出入り長柄ブラシ／浴槽手すり・移乗ボード・浴槽内椅子

杖の種類：手のひら・前腕・腋窩のどこで支えるか

杖特徴向いている人
T字杖最も多く使われる軽い歩行障害
多点杖（3点・4点）支持基底面が広く安定立位が不安定・歩行訓練の初期
ウォーカーケイン4点杖よりさらに広い歩行訓練の開始直後・介助レベル
ロフストランドクラッチ前腕カフ付き中等度の歩行障害・握力低下
カナディアンクラッチ上腕カフ付き上腕三頭筋の筋力低下
プラットフォームクラッチ前腕で体重を受ける関節リウマチなど手・手指の痛みや変形
松葉杖腋窩当て＋握り荷重量を自由に選べ幅広く使える

杖の合わせ方と、歩行器・車いす

歩行器・歩行車

固定型（持ち上げて前へ）／交互型（左右交互に）／四輪歩行車（前腕支持で安定）。段差がある場所では使えない

つながり

杖は支持基底を広げる道具。片側杖の歩き方はテーマ4、住宅改修や福祉用具購入の介護保険の上限額はリハビリテーション医療で学んだ。

テーマ4 杖歩行

施術の場面で意識したいこと

  • 杖の握りの高さは大転子の高さ（肘約30°屈曲）が基本。杖が長すぎ・短すぎに見えたら、処方した医療職や福祉用具の担当者に相談するよう伝える。
  • 関節リウマチで手指に痛みのある人は、プラットフォームクラッチなど前腕で支える杖を使っていることがある。

見ないで言ってみよう

T字杖はどちらの手で持ち、どこにつき、握りの高さはどこ？

健側の手で持ち、足部の前外側15cmにつく。握りは大転子の高さ（肘約30°屈曲）。

松葉杖の長さの簡単な決め方と、腋窩当ての位置は？

身長 − 41cm。腋窩当ては腋窩前縁から2横指下（腋窩を圧迫しない）。

ソックスエイドは何のための自助具？

リーチが困難な人が靴下・ストッキングを履くため。

要点
  • 自助具は残存能力・予後・場所・目的で選ぶ。過剰なサポートは能力を下げる
  • T字杖：健側・前外側15cm・大転子の高さ・肘約30°屈曲

テーマをまたいで思い出す

ギプス固定中の膝で、筋力を保つために使える訓練と、その注意点は？

等尺性筋力増強訓練（4〜6秒の最大等尺性収縮）。血圧が上がるので息を止めない。

尺骨神経麻痺で起こる手の形と、使う装具は？

鷲手（手内在筋劣位の手：MCP過伸展・PIP・DIP屈曲）。ナックルベンダー（MCP屈曲補助）。

失語症の人とのコミュニケーションで、構音障害の人には有効なのに使えない道具は？

50音表。失語症では文字言語も障害される。

感覚麻痺のある部位に禁忌となる物理療法は？

表在性温熱（ホットパックなど）・赤外線。熱傷のおそれがある。
